# Reconstruction Notice

This project is a local reconstruction of the UMGC CMSC 115 Unit 8 Lab 1
JUnit environment created because the assigned UMGC Virtual Lab / VM was
inaccessible during completion of the assignment.

The original `BuggyProgram.java` starter supplied through the course materials
was preserved. The original instructor JUnit source files could not be accessed.
`Task1Test.java`, `Task2Test.java`, and `Task3Test.java` were therefore created
with assistance from an AI large language model (OpenAI ChatGPT) to provide
functionally similar debugging exercises based on the visible lab description.

These reconstructed tests are not claimed to be exact copies of the official
instructor tests. If the official VM/tests become available, those tests should
be used for final verification and should take precedence over this reconstruction.
